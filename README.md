# 宅建MASTER

宅地建物取引士（宅建）試験向けの、ブラウザで動作する学習アプリです。

## 使い方

`index.html` をブラウザで開いてください。サーバー、ログイン、ビルドは不要です。

## 機能

- 四肢択一のオリジナル学習問題と解説
- 分野別の学習と弱点を優先した演習
- 間隔反復を使った復習計画
- 正答率・進捗の可視化
- ブラウザ内での学習履歴保存とバックアップ

## 注意事項

このアプリは初期版です。収録問題は公式の過去問集ではありません。宅建業法・民法などは法改正により正解が変わる可能性があるため、受験する年度の最新法令と公的な試験情報を確認してください。

## 技術構成

HTML / CSS / JavaScript（単一ファイル）

## 公開

GitHub Pages を利用する場合は、リポジトリの Settings → Pages → Deploy from a branch → main / (root) を選択してください。
